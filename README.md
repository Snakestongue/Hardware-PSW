## Instructions
In this PSW you'll explore in arm.java and laser.java and practice Encoders & Laser Can.

## What is this?

This is a Github repository with predesigned Hardware (mostly sensors) questions. This is a Pre-Season=Workshop designed to help young students learn and practice! It's a repository meant to be forked and edited as needed.
